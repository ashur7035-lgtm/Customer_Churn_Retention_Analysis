# Power BI Dashboard – Customer Churn & Retention Analysis

## 📌 Project Overview

This Power BI dashboard was developed to analyze customer churn behavior and identify key factors affecting customer retention.

The dashboard was built using the cleaned dataset generated during the Python data cleaning and preprocessing phase of the project.

The analysis provides interactive insights into customer demographics, contract types, tenure, internet services, revenue, and churn trends.

---

## 🛠 Tools Used

* Power BI Desktop
* DAX
* Power Query
* Python (Data Cleaning & Preprocessing)
* CSV Dataset

---

## 📊 Dashboard Features

### KPI Cards

* Total Customers
* Churned Customers
* Retained Customers
* Churn Rate %
* Total Revenue
* Average Monthly Charges

### Analysis Visuals

* Churn by Contract Type
* Churn by Tenure Group
* Churn by Age Group
* Tech Support Impact
* Internet Service vs Churn
* Monthly Charges Analysis
* Revenue by Contract Type

### Interactive Filters

* Gender
* Contract Type
* Internet Service
* Tenure Group
* Age Group

---

## 📌 Key Insights

* Month-to-Month customers showed the highest churn.
* Customers with low tenure were more likely to leave.
* Customers without Tech Support had higher churn rates.
* Higher Monthly Charges increased churn probability.
* Fiber Optic users showed elevated churn behavior.

---

## 💡 Business Recommendations

* Encourage long-term contracts through discounts.
* Improve onboarding for new customers.
* Strengthen technical support services.
* Provide loyalty and retention programs.
* Address issues affecting Fiber Optic customers.
